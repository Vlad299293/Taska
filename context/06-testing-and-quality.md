# 06-testing-and-quality.md

## Стратегия тестирования

### 1. Пирамида тестирования
- **Unit-тесты (Высокий приоритет)**: Тестирование чистого кода (Pure Functions). Основной фокус — `lib/planner.ts`, так как там сосредоточена математика распределения задач по блокам.
- **Тесты БД**: `tests/db.test.ts` прогоняет настоящие миграции и триггеры на SQLite в памяти (`node:sqlite`): авторизация, учёт времени, завершение сессии.
- **Ручное тестирование**: Проверка UX/UI и флоу сессий.

### 2. Критерии качества
- **Корректность расчета**: Сумма всех рабочих блоков в сессии не должна превышать `window_min` за вычетом перерывов.
- **Атомарность**: Завершение блока должно гарантированно обновить и `SessionBlocks`, и `Tasks`.
- **Производительность**: Локальная БД, сетевых задержек нет.

### 3. Инструменты
- **Test Runner**: Node.js native test runner через tsx (`npm test`).
- **Линтинг**: `npm run typecheck`.
