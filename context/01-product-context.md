# 01-product-context.md

## Видение продукта
Taska — это инструмент для тех, кому сложно оценивать время выполнения задач и кто склонен к прокрастинации. В отличие от классических To-Do листов, Taska фокусируется не на списке дел, а на их распределении во времени (сессиях).

## Цели
- Помочь пользователю сфокусироваться на одной задаче за раз.
- Гарантировать регулярные перерывы для предотвращения выгорания.
- Предоставить прозрачную картину потраченного времени.

## Пользовательские роли
- **Пользователь (User)**: Создает задачи, планирует сессии, отмечает прогресс.
- **Владелец воркспейса (Workspace Owner)**: Управляет доступом к общему пространству задач.

## Основные сценарии (User Stories)
1. **Создание задачи**: Пользователь оценивает задачу в минутах (кратно 5), задает приоритет и дедлайн.
2. **Запуск сессии**: Пользователь определяет «окно» времени (например, 2 часа), и система распределяет задачи в этом окне, перемежая их перерывами.
3. **Работа по блокам**: Система ведет пользователя по цепочке блоков: `Работа (30м) -> Перерыв (5м) -> Работа (30м)`.
4. **Завершение**: По окончании блока время автоматически списывается с задачи. Если задача завершена (потраченное время >= оценке), она переходит в статус `done`.
