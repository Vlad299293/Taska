# 02-domain-glossary.md

## Основные термины

| Термин | Описание |
| :--- | :--- |
| **Воркспейс (Workspace)** | Изолированное пространство для задач. Может быть личным или общим. |
| **Задача (Task)** | Единица работы с оценкой времени (`estimate_min`), приоритетом и статусом. |
| **Сессия (Session)** | Ограниченный период времени (`window_min`), в течение которого пользователь работает над набором задач. |
| **Блок (Block)** | Минимальный временной отрезок внутри сессии. Бывает двух типов: `work` (работа) и `break` (перерыв). |
| **Оценка (Estimate)** | Предполагаемое время выполнения задачи в минутах (кратно 5). |
| **Потраченное время (Spent Time)** | Фактическое время, которое было списано с завершенных рабочих блоков, привязанных к задаче. |
| **Бэклог (Backlog)** | Список задач, которые еще не были взяты в работу в текущей сессии. |
| **Пауза (Paused)** | Статус задачи, над которой начали работать, но сессия завершилась до её полного выполнения. |
