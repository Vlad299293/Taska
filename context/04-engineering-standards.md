# 04-engineering-standards.md

## Стандарты разработки

### 1. TypeScript
- Строгая типизация всех интерфейсов.
- Использование `type` для простых объединений и `interface` для структур данных.
- Избегать `any` любой ценой.

### 2. Frontend (React/Next.js)
- **Компоненты**: Функциональные компоненты с использованием хуков.
- **Стилизация**: CSS-модули или глобальный CSS (согласно текущему `globals.css`).
- **Client Components**: Использование директивы `'use client'` только там, где необходима интерактивность.

### 3. Backend & Database
- **Миграции**: Изменения схемы — только новым элементом массива `MIGRATIONS` в `lib/db-local.ts`; старые не правим.
- **Ограничения**: Валидные значения закрепляются `CHECK`/`UNIQUE` в схеме, а не только в форме.
- **Бизнес-логика**: Критическая логика (расчет времени, смена статусов) живёт в триггерах SQLite для атомарности.
- **SQL**: Только параметризованные запросы (`?`). Имена колонок из внешних данных в SQL не подставляем, только из закрытого списка.
- **Пароли**: Только хеш (PBKDF2), см. `lib/passwords.ts`.

### 4. Тестирование
- **Unit-тесты**: Логика планировщика (`planner.ts`) должна быть покрыта тестами в `tests/`.
- **Запуск**: `npm run test`.
