# 04-engineering-standards.md

## Стандарты разработки

### 1. TypeScript
- Строгая типизация всех интерфейсов.
- Использование `type` для простых объединений и `interface` для структур данных.
- Избегать `any` любой ценой.

### 2. Frontend (React/Next.js)
- **Компоненты**: Функциональные компоненты с использованием хуков.
- **Стилизация**: CSS-модули или глобальный CSS (согласно текущему `globals.css`).
- **Client Components**: Использование директивы `'use client'` только там, где необходима интерактивность.

### 3. Backend & Database
- **Миграции**: Все изменения схемы БД должны быть зафиксированы в `.sql` файлах в `supabase/migrations`.
- **Безопасность**: Любая новая таблица ОБЯЗАТЕЛЬНО должна иметь включенный `enable row level security`.
- **Бизнес-логика**: Критическая логика (расчет времени, смена статусов) выносится в Database Functions (RPC) для обеспечения атомарности и безопасности.

### 4. Тестирование
- **Unit-тесты**: Логика планировщика (`planner.ts`) должна быть покрыта тестами в `tests/`.
- **Запуск**: `npm run test`.
