# Project Context

This directory contains the project's architectural and product context used for Software Design Documents (SDD) and further development.

## Structure
- `ADR/`: Architecture Decision Records.
- `changes/`: Change logs and migration history.
- `00-start-here.md`: Onboarding and project entry point.
- `01-product-context.md`: Business goals, user personas, and product vision.
- `02-domain-glossary.md`: Ubiquitous language and domain terms.
- `03-architecture.md`: High-level system design and components.
- `04-engineering-standards.md`: Coding guidelines and patterns.
- `05-security-and-compliance.md`: Security protocols and requirements.
- `06-testing-and-quality.md`: Testing strategies and QA standards.
- `07-anti-patterns.md`: Patterns to avoid.
- `failure-log.md`: Record of mistakes and lessons learned.
