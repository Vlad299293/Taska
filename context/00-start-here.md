# 00-start-here.md

Добро пожаловать в Taska — систему управления временем и задачами.

## О проекте
Taska — это планировщик, который помогает пользователям бороться с прокрастинацией и выгоранием, распределяя задачи на фиксированные интервалы времени (рабочие блоки и перерывы). 

Основная идея: «полчаса на задачу, пять минут на перерыв».

## Быстрый старт для разработчика
1. **Стек**: Tauri 2, Next.js 15, React 19, TypeScript, SQLite.
2. **База данных**: локальная SQLite, схема и триггеры в `lib/db-local.ts`.
3. **Запуск**: `npm run tauri dev`
4. **Тесты**: `npm test`, типы: `npm run typecheck`

## Как работать с этим репозиторием (SDD Flow)
Все изменения в функционале должны проходить через процесс SDD (Software Design Document):
1. **Контекст**: Ознакомьтесь с документами в папке `/context`.
2. **Спецификация**: Создайте SDD (в папке `/sdd` или аналогичной), описывающий *что* нужно изменить и *почему*.
3. **Согласование**: Получите подтверждение архитектурного подхода.
4. **Реализация**: Напишите код, следуя спецификации.
5. **Документирование**: Обновите ADR или логи изменений, если архитектура изменилась.
