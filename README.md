# Taska

Десктопный планировщик дел: задачи делятся на блоки по 30 минут, между блоками перерыв 5 минут.

Стек: Tauri 2 (Rust), Next.js 15 (статический экспорт), React 19, TypeScript, SQLite (`tauri-plugin-sql`).
Все данные хранятся локально, в файле `taska.db` в папке данных приложения. Интернет не нужен.

## Запуск

- `npm install`
- `npm run tauri dev` — приложение в режиме разработки
- `npm test` — тесты (планировщик, база данных, авторизация, ошибки)
- `npm run typecheck` — проверка типов

Сборка установщика описана в [BUILDING.md](BUILDING.md).

> `npm run dev` запускает только веб-часть в браузере. Без оболочки Tauri базы данных нет, поэтому приложение
> покажет сообщение о том, что его нужно запускать через `npm run tauri dev`.

## Вход

Регистрация: никнейм (уникальный без учёта регистра), почта, пароль от 8 символов. Вход: почта или никнейм и пароль.
Пароли хранятся только в виде хеша PBKDF2-SHA256 с солью. Аккаунты локальные: восстановления пароля нет, а данные не
покидают этот компьютер.

## База данных

Схема и миграции лежат в `lib/db-local.ts` (версия схемы хранится в `PRAGMA user_version`). Бизнес-логика, которая
раньше жила в функциях Postgres, теперь реализована триггерами SQLite, чтобы учёт времени оставался атомарным:

- `complete_block` — при завершении рабочего блока время списывается с задачи, выполненная задача уходит в «Готово»;
- `finish_session` — при завершении сессии незавершённые задачи уходят в «Пауза» или обратно в Backlog;
- `profile_creates_workspace` — новый профиль получает личное рабочее пространство.
