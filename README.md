# Taska

Планировщик дел: задачи делятся на блоки по 30 минут, между блоками перерыв 5 минут.

Стек: Next.js, Supabase (Postgres, Auth, Realtime, Edge Functions), Vercel.

## Запуск

- npm install
- npm run dev
- npm test (тесты логики планирования)

Переменные окружения (необязательно, по умолчанию зашит публичный ключ проекта):
NEXT_PUBLIC_SUPABASE_URL и NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY.

## Вход

Регистрация: никнейм (уникальный без учёта регистра), почта, пароль. Вход: почта и пароль или никнейм и пароль.
Регистрация и вход идут через Edge Function auth (supabase/functions/auth): она проверяет уникальность никнейма, ищет почту по никнейму и выдаёт сессию. Почта при регистрации не подтверждается, восстановления пароля пока нет.

## База данных

Схема лежит в supabase/migrations. Доступ к данным ограничен защитой на уровне строк (RLS) по рабочим пространствам.
